# 4-week plan

Aim: be comfortable with the common patterns behind most online assessment and first-round interview questions, and solve a medium problem in about 25 to 30 minutes.

## Daily routine (about 1.5 to 2 hours)

| Block | Time | What |
|---|---|---|
| New problems | 60 to 75 min | Two new problems from today's topic. Use the 20-minute rule from the README. |
| Revision | 20 min | One older problem you needed hints for. Re-implement it from scratch. |
| Notes | 10 min | Update the header: approach, complexity, what went wrong. Run the progress script and commit. |

Commit after every problem with a message such as `Add Two Sum (arrays-hashing)`. Small commits show steady work.

## Week 1: arrays, hashing, two pointers, sliding window

Python tools to know: `dict`, `set`, `collections.Counter`, `collections.defaultdict`, slicing, sorting with `key=`.

- Day 1: Two Sum, Contains Duplicate, Valid Anagram
- Day 2: Group Anagrams, Top K Frequent Elements, Product of Array Except Self
- Day 3: Valid Palindrome, Two Sum II (sorted input), 3Sum
- Day 4: Container With Most Water, Best Time to Buy and Sell Stock
- Day 5: Longest Substring Without Repeating Characters, Longest Repeating Character Replacement
- Day 6: Revise every problem where you needed hints
- Day 7: Timed session: 3 mediums in 90 minutes

## Week 2: stack, binary search, linked lists

Python tools: a `list` as a stack, `collections.deque`, `bisect`, a dummy head node for linked lists.

- Day 8: Valid Parentheses, Min Stack, Daily Temperatures
- Day 9: Binary Search, Search a 2D Matrix, Koko Eating Bananas
- Day 10: Search in Rotated Sorted Array, Find Minimum in Rotated Sorted Array
- Day 11: Reverse Linked List, Merge Two Sorted Lists, Linked List Cycle
- Day 12: Remove Nth Node From End of List, Reorder List
- Day 13: LRU Cache (hash map plus doubly linked list), then revise
- Day 14: Timed session: 3 mediums in 90 minutes

## Week 3: trees and graphs

Python tools: recursion (set the recursion limit only if needed), `collections.deque` for BFS, adjacency lists with `defaultdict(list)`.

- Day 15: Invert Binary Tree, Maximum Depth of Binary Tree, Same Tree
- Day 16: Binary Tree Level Order Traversal, Validate Binary Search Tree
- Day 17: Lowest Common Ancestor of a BST, Kth Smallest Element in a BST
- Day 18: Number of Islands, Max Area of Island, Rotting Oranges
- Day 19: Clone Graph, Course Schedule (cycle detection)
- Day 20: Pacific Atlantic Water Flow, then revise
- Day 21: Timed session: 3 mediums in 90 minutes

## Week 4: dynamic programming, greedy, heaps, intervals, mocks

Python tools: `functools.lru_cache`, `heapq`, sorting intervals by start.

- Day 22: Climbing Stairs, House Robber, Coin Change
- Day 23: Longest Increasing Subsequence, Word Break
- Day 24: Jump Game, Merge Intervals, Insert Interval
- Day 25: Kth Largest Element in an Array, Task Scheduler
- Day 26: Full revision of the hint-marked problems
- Day 27: Mock assessment: 3 problems in 90 minutes with no hints, in an online editor
- Day 28: Review the mock, list your weakest two topics, and plan the next two weeks around them

## Other things to keep in the habit

- **Say your approach out loud** before you code, as you would in an interview.
- **Test with an empty input and a single element** every time.
- **Do not collect problems.** Ten you understand deeply beat fifty you half remember.
- **Rest one day a week** if you have been consistent. Burnout ends more plans than difficulty does.
